{{- /* Open the site in the visitor's language. Runs only on the default-language home page ("/"), synchronously in so the redirect happens before anything is painted. 1. If the visitor picked a language in the header switcher, that choice (localStorage "pref-lang") wins. 2. Otherwise, use the first browser language (navigator.languages) that the site has, e.g. en-GB -> /en/, es-AR -> /es/. 3. No match: stay on the default language. Crawlers are not redirected, so the default home stays indexable; the other languages are discoverable through the hreflang alternate links. Deep links (posts, tags...) are never redirected: a shared link opens as sent. */ -}} {{- $homes := dict -}} {{- range hugo.Sites -}} {{- $homes = merge $homes (dict .Language.Lang .Home.RelPermalink) -}} {{- end -}} {{- $defaultLang := hugo.Sites.Default.Language.Lang -}}
